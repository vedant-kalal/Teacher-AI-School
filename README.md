# 🎓 AI Teacher — Multi-Agent Educational Lesson System

An advanced, real-time AI-powered teaching platform that delivers complete school lessons through an interactive blackboard interface. The system uses a **multi-agent architecture** to generate narrated lessons with synchronized blackboard writing, AI-generated images, educational diagrams, 3D visualisations, and motion videos — all streamed live to the student's browser.

## 🌟 Project Overview

The AI Teacher is a school-grade educational system that teaches any topic to students aged **10–12 years** from absolute basics. It works like a real classroom:

- A **virtual teacher** appears at the front and speaks in **Hinglish** (natural Hindi-English mix with Devanagari script), the way real Indian school teachers talk.
- A **blackboard** fills the screen. Text, definitions, formulas, and bullet points are written on it segment by segment — just like chalk on a board.
- **AI-generated images and diagrams** appear at the right side of the board at precisely the right moments, timed to match what the teacher is explaining.
- **Educational videos** (generated by Google Veo 3.1) show moving processes like blood flowing through a heart, a water cycle, or an engine working.
- The whole lesson is **streamed live** using Server-Sent Events (SSE) — each piece appears in real time, synchronized with the narration audio.

## 🤖 Python Teaching Agents

All 13 agents live in `python_backend/agents/teaching_agents.py` and `python_backend/agents/video_coordinator_agent.py`. Each is an independent Python class that calls OpenAI via LangChain's `ChatOpenAI`.

### 1. `ScriptPlannerAgent`
**Model:** `gpt-4o-mini`  
**Role:** Creates the complete lesson script with **10–14 segments** for a given topic.  
Each segment includes:
- `narration_text` — what the teacher says (4–6 sentences, simple language)
- `board_text` — what appears on the blackboard (definitions, examples, key points)
- `board_style` — `title`, `heading`, `text`, `formula`, `bullet`, or `highlight`
- `needs_visual` — whether this segment needs an image or diagram
- `visual_type` — `image`, `diagram`, `3d_model`, or `video`
- `visual_prompt` — detailed generation prompt
- `clear_board` — whether to wipe the board before this segment
- `complex_terms` — hard words that need simpler explanation

If the AI returns invalid JSON it falls back to a safe two-segment starter lesson.

---

### 2. `ScriptAnalyzerAgent`
**Model:** `gpt-4o`  
**Role:** Receives the **full script** (all segments at once) and plans **4–8 strategic visuals** for the entire lesson upfront — before teaching starts.  
Output per visual:
- `visual_id`, `target_segment_id`, `visual_type`
- `trigger_phrase` — the exact narration sentence that should trigger this visual
- `title`, `detailed_prompt`, `importance` (`critical` / `important` / `supplementary`)
- `display_duration_ms`, `position` (`right` / `left` / `center` / `fullscreen`)

---

### 3. `VisualCoordinatorAgent`
**Model:** `gpt-4o-mini`  
**Role:** During each segment, decides **whether to show a visual right now** and which one, based on the current narration text and what has already been shown.  
Returns: `show_visual`, `visual_to_show` (visual_id), `display_duration_ms`, `reason`.

---

### 4. `VisualGeneratorAgent`
**Model:** `gpt-4o`  
**Role:** Takes a planned visual and the **full script context** to craft an enhanced, highly detailed generation prompt that accurately matches what the teacher is explaining at that moment.  
Returns: `enhanced_prompt`, `style_hints`, `negative_prompt`, `recommended_size`, `visual_type`.

---

### 5. `NarrationAgent`
**Model:** `gpt-4o-mini`  
**Role:** Expands each segment's base narration into a **full 5–8 sentence teacher speech**. When a visual is being displayed, it also describes every visible element (labels, arrows, colours) so students know what to look at.  
Also has a `describe_visual()` method for standalone visual introductions.

---

### 6. `BoardWriterAgent`
**Model:** `gpt-4o-mini`  
**Role:** Formats raw board text for a real blackboard:
- Strips all markdown (`#`, `**`, `` ` ``)
- Converts ASCII symbols → proper Unicode (`->` → `→`, `sqrt` → `√`, `pi` → `π`)
- Converts `-` list items → `•` bullet points
- Adds teacher-style emojis (`📝 💡 ⭐`)

---

### 7. `DeciderAgent`
**Model:** `gpt-4o-mini`  
**Role:** Controls **lesson pacing** for each segment. Returns:
- `should_clear_board` — true if board is > 70% full
- `should_generate_visual` — whether a visual is needed
- `visual_priority` — 1 (immediate), 2 (can wait), 3 (optional)
- `pacing` — `slow`, `normal`, or `fast` (controls character typing speed: 70ms / 50ms / 30ms)

---

### 8. `BoardLayoutAgent`
**Model:** `gpt-4o-mini`  
**Role:** Decides the **board layout** for each page — text size, image size, positions, spacing. Output:
- `text_size` — `small` / `medium` / `large`
- `text_width_percent` — 55–65% when an image is present, 100% otherwise
- `image_size` — always `large` for visibility
- `image_width_percent` — 35–45%
- `image_position` — `right`
- `line_spacing` — `compact` / `normal` / `relaxed`
- `layout_reason` — explains the decision

---

### 9. `ImageSourceAgent`
**Model:** `gpt-4o-mini`  
**Role:** Decides whether to use a **real photograph** (from Pexels) or an **AI-generated image** (from `gpt-image-1`).
- Real photos are preferred for: animals, planets, famous places, scientific photographs, real objects.
- AI generation is preferred for: custom diagrams, abstract concepts, step-by-step processes, custom infographics.  
Returns: `source` (`real` | `ai_generated`), `search_query` (for Pexels), `ai_prompt`, `reason`.

---

### 10. `UniqueContentAgent`
**Model:** `gpt-4o`  
**Role:** Validates the full script to ensure **no two segments repeat** the same teaching content. Also ensures smooth **transitions** between segments (e.g., "Building on what we learned…") and that the lesson ends with a proper **conclusion** ("Thank you for learning with me today!").  
Returns: `is_valid`, `issues`, `suggested_transitions`, `needs_conclusion`, `conclusion_text`.

---

### 11. `ImageAnalyzerAgent`
**Model:** `gpt-4o-mini`  
**Role:** Pre-analyses what an image will contain (based on its generation prompt) and produces a **teaching guide**:
- `key_elements` — main things to notice
- `teaching_points` — specific things to explain about the image
- `student_focus` — what students should look at first
- `suggested_questions` — questions to ask about the image
- `explanation_script` — a 2–3 sentence script for introducing the image

---

### 12. `VideoCoordinatorAgent`
**File:** `python_backend/agents/video_coordinator_agent.py`  
**Model:** `gpt-4o`  
**Role:** Analyzes lesson segments and plans **1–3 educational videos** that show concepts in motion. Chooses video types: `process_flow`, `working_model`, `animation`, `demonstration`, `cycle`, or `comparison`.  
Only suggests videos for concepts that **genuinely benefit from motion** (e.g., blood flowing, gears turning, the water cycle). Provides highly detailed `subject` descriptions for video generation.

---

### 13. `HinglishNarrationAgent`
**Model:** `gpt-4o`  
**Role:** Converts English narration into **Hinglish** — the natural mix of Hindi and English that real Indian school teachers use. Hindi words are written in **Devanagari script** (not Roman transliteration) for correct TTS pronunciation.  
Examples:
- "Let me explain how this works" → "चलो, मैं तुम्हें समझाता हूं कि यह कैसे काम करता है"
- "This is very important" → "यह बहुत important है, ध्यान से सुनो"
- "A black hole is very powerful" → "देखो बच्चों, black hole बहुत powerful होता है"  
Technical and scientific terms stay in English.

## 🔄 Complete Agentic Flow

This is the end-to-end flow from a user entering a topic to the finished lesson on screen.

```
USER enters a topic (e.g. "The Solar System")
           │
           ▼
[1] POST /api/stream/lesson/start  (browser → Mastra port 5000)
           │  Mastra proxies to →
           ▼
[2] POST /api/stream/lesson/start  (Mastra → Python port 8001)
    • Generates a run_id (UUID)
    • Creates a LessonStreamer (SSE event queue)
    • Fires asyncio.create_task(start_streaming_lesson(run_id, topic))
    • Returns { runId, status: "STARTED", streamUrl }
           │
           ▼
[3] Browser opens SSE connection:
    GET /api/stream/lesson/{runId}  (proxied to Python)
           │
           ▼
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PHASE 1 — SCRIPT PLANNING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[4] ScriptPlannerAgent.plan_lesson_script(topic)
    → GPT-4o-mini creates full script with 10-14 segments
    → status_update "Planning lesson script..." (5%)

[5] UniqueContentAgent.validate_and_enhance_script(script)
    → GPT-4o checks for repeated content, adds transitions
    → Ensures a proper closing "Thank you" segment exists

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PHASE 2 — VISUAL PLANNING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[6] ScriptAnalyzerAgent.analyze_script_for_visuals(script)
    → GPT-4o reads the FULL script
    → Plans 4-8 strategic visuals with trigger phrases
    → status_update "Analyzing script for visual content..." (10%)

[7] VideoCoordinatorAgent.analyze_for_videos(segments)
    → GPT-4o plans 1-3 educational videos
    → Chooses which segments need motion visualization
    → status_update "Planning educational videos..." (12%)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PHASE 3 — PARALLEL PRE-GENERATION (background tasks)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[8] For each planned visual (runs in parallel):
    a. VisualGeneratorAgent.generate_enhanced_prompt(visual, script)
       → GPT-4o creates a detailed, context-aware generation prompt
    b. ImageSourceAgent.decide_image_source(prompt, type, topic)
       → GPT-4o-mini: real Pexels photo OR AI-generated?
    c. ImageAnalyzerAgent.analyze_image_for_teaching(prompt, type, topic)
       → Pre-generates teaching guidance for the image
    d. asyncio.create_task(get_images_with_fallback())
       → If real: search Pexels API (2 photos)
       → If AI: POST to gpt-image-1 → base64 PNG

[9] For each planned video (runs in parallel):
    asyncio.create_task(generate_video_with_metadata(...))
    → POST to Google Veo 3.1 Fast → base64 MP4

    status_update "Pre-generating visual content..." (15%)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PHASE 4 — LIVE LESSON DELIVERY (one segment at a time)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[10] emit lesson_start event → Browser shows lesson title

For each segment (idx 0 … N):

  [10a] DeciderAgent.decide_next_action(segment, remaining, board_fill%)
        → Decides: clear board? pacing (slow/normal/fast)?

  [10b] If board is full or segment.clear_board=true:
        → emit board_clear event → Browser animates fade-out

  [10c] VisualCoordinatorAgent.coordinate_visuals(plan, segment_id, narration)
        → Decides: show a visual now? which one?

  [10d] BoardLayoutAgent.plan_page_layout(text, has_image, image_info)
        → Decides: text size, image size, image position
        → emit layout_update event → Browser adjusts CSS grid

  [10e] BoardWriterAgent.format_board_content(text, style, topic)
        → Strips markdown, adds Unicode symbols, formats bullets
        → emit board_write event → Browser types text character-by-character

  [10f] If visual is ready (from parallel tasks):
        → emit media_ready event → Browser shows image/diagram in right panel
        (Multiple images stacked in scrollable gallery)

  [10g] NarrationAgent.expand_narration(base_text, topic, board, visual_context)
        → GPT-4o-mini expands to 5-8 sentence teacher speech
        → Describes visible image elements when image is on screen

  [10h] HinglishNarrationAgent.convert_to_hinglish(english_text, topic)
        → GPT-4o converts to Hinglish with Devanagari Hindi script

  [10i] generate_hinglish_voice_openai(hinglish_text, use_male_voice=True)
        → OpenAI gpt-audio-mini with ash/nova voices → base64 MP3
        → emit voice_audio event → Browser plays audio
        (Falls back to browser TTS if voice generation fails)

  [10j] emit narration_segment event → Browser receives text for fallback TTS

  [10k] If video task for this segment is done:
        → emit video_ready event → Browser shows looping MP4 video

  [10l] await asyncio.sleep(max(board_write_duration, narration_duration))
        → Synchronized pause before next segment

  [10m] emit pause event → Short gap between segments

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  PHASE 5 — LESSON WRAP-UP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[11] Show up to 3 remaining unshown visuals

[12] emit lesson_end event → Browser shows completion state
```

## 📦 Streaming Workflow Steps

The `run_streaming_lesson()` function in `python_backend/workflows/streaming_workflow.py` executes these steps in order:

| Step | Progress | Action |
|---|---|---|
| 1 | 5% | `ScriptPlannerAgent` — create structured 10-14 segment script |
| 2 | 8% | `UniqueContentAgent` — validate unique content, add transitions |
| 3 | 10% | `ScriptAnalyzerAgent` — pre-plan all visuals for full script |
| 4 | 12% | `VideoCoordinatorAgent` — plan educational videos |
| 5 | 15% | Start **parallel image/video generation** tasks in background |
| 6 | 20–90% | Per-segment teaching loop (board write + narration + visuals) |
| 7 | 95% | Display any remaining unshown visuals |
| 8 | 100% | `lesson_end` event — lesson complete |

## 📡 SSE Event Types

Events flow from Python → Mastra proxy → Browser as JSON in the `data:` field of SSE.

| Event Type | When | Key Data Fields |
|---|---|---|
| `lesson_start` | Lesson begins | `topic`, `title`, `run_id` |
| `status_update` | Progress milestones | `message`, `progress` (0.0–1.0) |
| `board_write` | Text appears on board | `text`, `style`, `color`, `size`, `char_delay_ms`, `duration_ms` |
| `board_clear` | Board wipes | `animation` (`fade`), `duration_ms` |
| `layout_update` | Board layout changes | `text_size`, `text_width_percent`, `image_size`, `image_width_percent`, `image_position` |
| `media_ready` | Image/diagram ready | `media_type`, `title`, `image_base64` OR `image_url`, `display_duration_ms` |
| `narration_segment` | Teacher speech text | `text`, `duration_ms`, `speed`, `pause_after_ms` |
| `voice_audio` | Hinglish audio ready | `audio_base64` (MP3), `text`, `is_hinglish` |
| `video_ready` | Educational video ready | `video_base64` OR `video_url`, `title`, `loop`, `video_type` |
| `pause` | Gap between segments | `duration_ms` |
| `lesson_end` | Lesson complete | `summary`, `total_segments` |
| `error` | Any failure | `message`, `code` |

## 🖥 Frontend UI

The React/Vite frontend (`web/src/`) renders the classroom experience.

### Components

| Component | File | Purpose |
|---|---|---|
| `App` | `App.tsx` | Root: manages lesson state, renders top bar and blackboard |
| `StreamingBlackboard` | `components/StreamingBlackboard.tsx` | Full-screen chalkboard, renders board text with typing animation, image gallery, video panel |
| `TopicInput` | `components/TopicInput.tsx` | Topic search box with quick-topic suggestions |
| `Blackboard` | `components/Blackboard.tsx` | Static blackboard renderer |
| `LessonProgress` | `components/LessonProgress.tsx` | Progress bar / status indicator |
| `MediaGallery` | `components/MediaGallery.tsx` | Scrollable image gallery (up to 6 images, object-fit: contain) |

### Custom Hook

`useLessonStream` (`hooks/useLessonStream.ts`):
- Opens SSE connection to `/api/stream/lesson/{runId}`
- Processes each event type and updates React state
- Manages `boardState` (text lines, layout config, images, videos)
- Plays audio using Web Audio API from base64 MP3
- Falls back to browser SpeechSynthesis if no voice audio

### UI Design Choices

- **Full-screen blackboard**: Dark green chalkboard feel, edge-to-edge
- **Two-panel layout** when images present: 60% text / 40% image gallery
- **Character-by-character typing**: Text appears like chalk writing
- **Auto-scroll**: Board and image gallery scroll as new content arrives
- **Hinglish audio**: High-quality OpenAI TTS, cached to avoid regeneration
- **Video looping**: Educational videos play on loop while teacher explains

## 🚀 How to Run

### Prerequisites

- Node.js 18+
- Python 3.11+
- PostgreSQL database
- OpenAI API key (or Replit AI Integrations)

### 1. Install dependencies

```bash
# Node.js
npm install

# Python (using uv — recommended)
uv sync
# or with pip:
pip install .
```

### 2. Build the frontend

```bash
cd web && npx vite build --outDir ../dist
```

### 3. Start all services

```bash
# Start everything (Mastra + Python)
./scripts/start-all.sh

# Or separately:
./scripts/start_python.sh    # Python FastAPI on port 8001
mastra dev                   # Mastra gateway on port 5000
```

### 4. Access the app

Open `http://localhost:5000/ui` in your browser.

### 5. Test via curl

```bash
# Start a lesson
curl -X POST http://localhost:5000/api/stream/lesson/start \
  -H "Content-Type: application/json" \
  -d '{"inputData": {"topic": "The Solar System"}}'

# Response: {"runId": "...", "status": "STARTED", "streamUrl": "/api/stream/lesson/..."}
```

### 6. Trigger cron test

```bash
npx tsx tests/testCronAutomation.ts
```
